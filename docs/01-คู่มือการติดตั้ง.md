# คู่มือการติดตั้งระบบ

ระบบประกอบด้วย 3 ส่วน: PostgreSQL, API (Node.js/Express) และ Web (Angular)

## 1. สิ่งที่ต้องเตรียม

| รายการ | เวอร์ชันขั้นต่ำ | หมายเหตุ |
| --- | --- | --- |
| Node.js | 18 LTS ขึ้นไป | แนะนำ 20 LTS |
| npm | 9 ขึ้นไป | มาพร้อม Node.js |
| PostgreSQL | 14 ขึ้นไป | ต้องตั้ง encoding เป็น UTF8 |
| หน่วยความจำ | 2 GB | สำหรับเครื่องเดียวใช้ทั้งบริษัท |
| เบราว์เซอร์ | Chrome/Edge รุ่นใหม่ | รองรับ Angular 20 |

ตรวจสอบเวอร์ชัน

```bash
node -v
npm -v
psql --version
```

## 2. เตรียมฐานข้อมูล

```bash
sudo -u postgres psql
```

```sql
CREATE DATABASE rental_debt ENCODING 'UTF8' TEMPLATE template0;
CREATE USER rental_app WITH PASSWORD 'รหัสที่ต้องการ';
GRANT ALL PRIVILEGES ON DATABASE rental_debt TO rental_app;
\c rental_debt
GRANT ALL ON SCHEMA public TO rental_app;
\q
```

> ถ้าใช้ PostgreSQL เวอร์ชัน 15 ขึ้นไป ต้อง grant สิทธิ์ schema public ตามด้านบน มิฉะนั้น migrate จะ error `permission denied for schema public`

## 3. ติดตั้ง API

```bash
cd backend
npm install
cp .env.example .env
```

แก้ไฟล์ `backend/.env`

```env
NODE_ENV=production
PORT=3000
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=rental_app
DB_PASSWORD=รหัสที่ต้องการ
DB_NAME=rental_debt
JWT_SECRET=สุ่มอย่างน้อย-32-ตัวอักษร
UPLOAD_DIR=/var/lib/rental-debt/uploads
LOG_DIR=/var/log/rental-debt
CORS_ORIGIN=https://debt.example.co.th
```

สร้างค่า JWT_SECRET แบบสุ่ม

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

สร้างตาราง

```bash
npm run migrate
```

ผลลัพธ์ที่ถูกต้องจะแสดงรายการตาราง/วิวที่สร้าง (`regions`, `hospitals`, `contracts`, `contract_periods`, `invoices`, `invoice_deliveries`, `cheques`, `cheque_allocations`, `attachments`, `audit_logs`, view `v_invoice_receivable`)

สตาร์ท

```bash
npm start
```

ตรวจสอบ

```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"<อีเมล admin>","password":"<รหัสผ่าน>"}'
```

## 4. ติดตั้ง Frontend (Angular)

```bash
cd frontend
npm install
npm run build      # ได้ไฟล์ที่ dist/frontend/browser
```

นำไฟล์ `dist/frontend/browser` ไปวางบน web server (Nginx/Apache) หรือ เสิร์ฟด้วย Node ก็ได้

### ตัวอย่าง Nginx

```nginx
server {
    listen 80;
    server_name debt.example.co.th;

    root /var/www/rental-debt/browser;
    index index.html;

    # Angular routing (path ใด ๆ ให้คืน index.html)
    location / {
        try_files $uri $uri/ /index.html;
    }

    # ส่งต่อไป API
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 12m;   # ให้อัปโหลดไฟล์ 10 MB ได้
    }
}
```

> ค่า `client_max_body_size` ต้องมากกว่า `MAX_UPLOAD_MB` ของ API ไม่งั้นอัปโหลด PDF จะได้ error 413

## 5. รันเป็น service (systemd)

`/etc/systemd/system/rental-debt-api.service`

```ini
[Unit]
Description=Rental Debt Tracking API
After=network.target postgresql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/rental-debt/backend
EnvironmentFile=/opt/rental-debt/backend/.env
ExecStart=/usr/bin/node src/index.js
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now rental-debt-api
sudo systemctl status rental-debt-api
```

## 6. สำรองข้อมูล

สำรองฐานข้อมูล (แนะนำทุกวัน ด้วย cron)

```bash
pg_dump -U rental_app -Fc rental_debt > /backup/rental_debt_$(date +%F).dump
```

สำรองโฟลเดอร์ไฟล์แนบ (`UPLOAD_DIR`) ด้วย เพราะเก็บ PDF ใบแจ้งหนี้และ scan เช็ค

กู้คืน

```bash
pg_restore -U rental_app -d rental_debt --clean /backup/rental_debt_2026-11-20.dump
```

## 7. บัญชีเริ่มต้นและความปลอดภัย

ระบบไม่มีบัญชีเริ่มต้น หลัง `npm run migrate` ให้เพิ่มบัญชี admin คนแรกในตาราง `users` เอง (role = `ADMIN`, รหัสผ่านเก็บเป็น bcrypt hash) จากนั้นสร้างผู้ใช้คนอื่นผ่านเมนู **ผู้ใช้งาน** (รหัสผ่านต้อง ≥ 8 ตัวอักษร)

รายการตรวจสอบก่อน go-live

- [ ] เปลี่ยน `JWT_SECRET` เป็นค่าสุ่มจริง
- [ ] ตั้ง `CORS_ORIGIN` เป็นโดเมนจริง (ไม่ใช่ `*`)
- [ ] เปิด HTTPS
- [ ] ตั้ง backup รายวันทั้งฐานข้อมูลและโฟลเดอร์ uploads
- [ ] ตรวจว่า `logs/app.log` ถูก rotate (logrotate)

## 8. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
| --- | --- |
| `permission denied for schema public` | PostgreSQL 15+ ต้อง `GRANT ALL ON SCHEMA public TO rental_app;` |
| `password authentication failed` | ตรวจ `DB_USER`/`DB_PASSWORD` ใน `.env` และ `pg_hba.conf` |
| วันที่ในรายงานเพี้ยน | ตรวจ timezone เครื่องเป็น `Asia/Bangkok` และฐานข้อมูลใช้ UTF8 |
| ฟอนต์ไทยไม่แสดงบน PDF ที่ export | ระบบสร้าง PDF ฝั่ง client — ใช้ Chrome รุ่นใหม่ |
| อัปโหลดไฟล์ไม่ผ่าน 413 | เพิ่ม `client_max_body_size` ที่ Nginx |
| หน้าเว็บขาวหลัง deploy | ยังไม่ได้ตั้ง `try_files ... /index.html` ทำให้ path ลึกโหลดไม่เจอ |
| login ได้แต่ข้อมูลว่าง | ผู้ใช้บทบาท REP จะเห็นเฉพาะโรงพยาบาลในพื้นที่ตัวเอง — ตรวจ `region_id` ของผู้ใช้ |
