# คู่มือการใช้งาน

## 1. ภาพรวมกระบวนการทำงาน

```
สัญญา/ใบสั่งจ้าง ──► ระบบสร้างงวดการเรียกเก็บอัตโนมัติ
                          │
                          ▼
                  ออกใบแจ้งหนี้ (รายงวด หรือหลายงวดพร้อมกัน)
                          │
                          ▼
                  บันทึกการจัดส่ง (ขนส่ง/ผู้แทน/อีเมล) + แนบ PDF
                          │
                          ▼
                  รับเช็คจากโรงพยาบาล (ตัดชำระใบแจ้งหนี้) + แนบ scan เช็ค
                          │
                          ▼
                  ติดตามสถานะเช็ค: ถึงบริษัท → นำฝาก → เงินเข้า / เด้ง
```

## 2. บทบาทผู้ใช้และสิทธิ์

| บทบาท | เห็นข้อมูล | ทำอะไรได้ |
| --- | --- | --- |
| ผู้ดูแลระบบ (ADMIN) | ทั้งหมด | ทุกอย่าง รวมจัดการผู้ใช้และดู audit log |
| ผู้จัดการ (MANAGER) | ทั้งหมด | จัดการสัญญา/โรงพยาบาล, ออกใบแจ้งหนี้, บันทึกเช็ค |
| ฝ่ายบัญชี (ACCOUNTING) | ทั้งหมด | ออก/ยกเลิกใบแจ้งหนี้, บันทึกเช็คและสถานะเช็ค |
| ผู้แทนพื้นที่ (REP) | เฉพาะโรงพยาบาลในพื้นที่ของตน | บันทึกการจัดส่ง, ดูรายงานของพื้นที่ตัวเอง |

## 4. ภาพรวม (Dashboard)

แสดง KPI ทั้งบริษัท (หรือตามตัวกรองภาค/ผู้แทน) ณ วันที่เลือก

| การ์ด | ความหมาย |
| --- | --- |
| งวดที่ยังไม่แจ้งหนี้ | งวดที่**เริ่มแล้ว**แต่ยังไม่ออกใบแจ้งหนี้ (ตัวเลขหลัก) และงวดที่ยังไม่เริ่ม (ตัวเลขรอง) |
| ค้างส่งใบแจ้งหนี้ | มูลค่าโดยประมาณของงวดที่เริ่มแล้วแต่ยังไม่แจ้งหนี้ |
| มูลค่าคงเหลือตามสัญญา | ยอดที่ยังไม่ถูกเรียกเก็บตลอดอายุสัญญาที่เหลือ |
| ออกใบแจ้งหนี้แล้ว | จำนวนใบและยอดรวม |
| รับเช็คแล้ว | จำนวนเช็ค ยอดรวม และ**อัตราการจัดเก็บ** (% เทียบยอดที่ออกใบแจ้งหนี้แล้ว) |
| รอรับเช็ค | ใบที่ออกแล้วแต่ยังไม่ได้รับเช็ค (จำนวน + ยอด) |

ส่วนล่างของหน้า: กราฟอายุหนี้, ความครบถ้วนของการส่งเอกสาร, สรุปตามผู้แทน, รายการงวดที่ยังไม่แจ้งหนี้, รายการใบแจ้งหนี้ที่ยังไม่ได้รับเช็ค

> ตัวกรอง "ณ วันที่" ใช้ค่าเริ่มต้นเป็นวันนี้ ไม่ต้องกรอกทุกครั้ง

## 5. สัญญาเช่า / ใบสั่งจ้าง

### 5.1 ดูรายการ

ค้นหาด้วยเลขที่สัญญาหรือชื่อโรงพยาบาล กรองตามภาค ผู้แทน และสถานะ คอลัมน์ **ความคืบหน้างวด** แสดง `แจ้งแล้ว/ทั้งหมด` พร้อมแถบ прогресс

### 5.2 สร้างสัญญาใหม่

1. กด **+ สร้างสัญญา** (เฉพาะ ADMIN/MANAGER)
2. เลือกโรงพยาบาล กรอกเลขที่สัญญา (เช่น `CT-2569-018`)
3. เลือกประเภทเอกสาร: สัญญาเช่า / ใบสั่งจ้าง / สัญญาระยะสั้น
4. กำหนดวันเริ่ม–สิ้นสุด และรอบการจ่าย (รายเดือน / ทุก 10 วัน / ทุก 15 วัน)
5. เลือกรูปแบบคิดเงิน
   - **เหมารายงวด (fixed rate)** → กรอกค่าเช่าต่องวด
   - **จ่ายตามใช้ (pay per use)** → กรอกราคาต่อหน่วย + ชื่อหน่วย (เช่น ภาพ, ครั้ง)
6. กรอกเครดิตเทอม (วัน) และ VAT (%)
7. เพิ่มรายการเครื่อง (ชื่อ, รุ่น, Serial, จำนวน) — ไม่บังคับ
8. ด้านขวาจะแสดง **ตัวอย่างงวดที่จะสร้าง** ทันที ถ้าจำนวนงวดไม่ตรงที่ต้องการ ให้ตรวจวันเริ่ม–สิ้นสุด
9. กด **บันทึกสัญญา**

ระบบจะสร้างงวดทั้งหมดทันที โดย `วันครบกำหนด = วันสิ้นสุดงวด + เครดิตเทอม`

### 5.3 รายละเอียดสัญญา

- การ์ด KPI: งวดที่ยังไม่แจ้งหนี้, มูลค่าคงเหลือ, รับเช็คแล้ว, ค้างรับชำระ
- ตารางงวด: ทุกงวดพร้อมสถานะใบแจ้งหนี้ การส่ง และการเงิน
- ปุ่ม **ออกใบแจ้งหนี้** ต่องวด (แสดงเฉพาะงวดที่เริ่มแล้วและยังไม่ออกใบ)
- ปุ่ม **ออกใบแจ้งหนี้ที่ค้าง N งวด** สำหรับสัญญาแบบเหมารายงวด — ออกย้อนหลังทีละหลายงวดในครั้งเดียว
- ปุ่ม **ต่อสัญญาใหม่** — คัดลอกเงื่อนไข/ราคา/เครื่องไปยังสัญญาปีถัดไป

> กรณีแบบ **จ่ายตามใช้** ระบบไม่รู้ปริมาณล่วงหน้า จึงไม่รองรับการออกหลายงวดพร้อมกัน ให้ออกทีละงวดและกรอกจำนวนหน่วยจริง

## 6. ใบแจ้งหนี้

### 6.1 รายการ

กรองตามโรงพยาบาล ผู้แทน สถานะการชำระ และช่วงวันที่ออก คอลัมน์ **การส่ง** บอกว่าส่งแล้วกี่ครั้ง/ล่าสุดเมื่อไร คอลัมน์ **อายุหนี้** แสดงจำนวนวันที่เกินกำหนด (ตัวแดง)

สถานะการชำระ (คำนวณอัตโนมัติ)

| สถานะ | เงื่อนไข |
| --- | --- |
| ยังไม่ส่ง | ยังไม่มีบันทึกการจัดส่ง และยังไม่ได้รับเช็ค |
| ส่งแล้ว รอเช็ค | มีบันทึกการจัดส่งแล้ว แต่ยังไม่ได้รับเช็ค |
| รับเช็คบางส่วน | ได้เช็คแล้วแต่ยอดน้อยกว่ายอดใบ |
| รับเช็คครบ | ยอดเช็คที่ตัดชำระ ≥ ยอดใบ |
| ยกเลิก | ถูกยกเลิกด้วยมือ (ไม่นับในรายงานค้างรับ) |

### 6.2 รายละเอียดใบแจ้งหนี้

- **ประวัติการจัดส่ง** (timeline): ทุกครั้งที่ส่ง ระบุวิธีส่ง ผู้รับ ขนส่ง เลขพัสดุ และผู้บันทึก
- ปุ่ม **+ บันทึกการจัดส่ง**: เลือกวันที่ วิธีส่ง (ขนส่ง→ผู้แทน, ขนส่ง→โรงพยาบาล, ผู้แทนรับที่บริษัท, พนักงานนำส่ง, อีเมล, ไปรษณีย์) ผู้รับ และสถานะ (ส่งถึงแล้ว/ระหว่างขนส่ง/ผู้รับตอบรับ/ตีกลับ)
- **ไฟล์แนบ**: อัปโหลด PDF ใบแจ้งหนี้ (หรือรูปถ่าย) คลิกเพื่อเปิดดู
- **เช็คที่ตัดชำระใบนี้**: รายการเช็คพร้อมสถานะ คลิกเพื่อไปหน้ารายละเอียดเช็ค
- ปุ่ม **ยกเลิกใบแจ้งหนี้** (ADMIN/MANAGER/ACCOUNTING) — ใช้เมื่อออกผิด ใบที่ยกเลิกแล้วจะไม่ถูกนับเป็นหนี้ค้าง

> **การส่งหลายครั้ง**: ถ้าเอกสารถูกตีกลับแล้วส่งใหม่ ให้บันทึกเพิ่มอีกครั้ง ระบบเก็บทุกครั้งไว้ ตรวจย้อนหลังได้ว่า "ไปเมื่อไร วิธีใด ถึงใคร"

## 7. เช็ค / การรับชำระ

### 7.1 บันทึกเช็คใหม่

1. กด **+ บันทึกเช็ค**
2. เลือกโรงพยาบาล → ระบบแสดง**ใบแจ้งหนี้ที่ยังค้างชำระ**ของโรงพยาบาลนั้น
3. กรอกเลขที่เช็ค ธนาคาร สาขา จำนวนเงิน วันที่หน้าเช็ค วันที่รับ
4. เลือกวิธีนำส่ง: ผู้แทนเข้าไปรับที่ รพ. / รพ. ส่งมาที่บริษัท / ผู้แทนนำส่งบริษัท / นำส่งด้วยตนเอง
5. ถ้าเช็คถึงบริษัทแล้ว ให้กรอก **วันที่ถึงบริษัท**
6. ติ๊กเลือกใบแจ้งหนี้ที่จะตัดชำระ (ระบบเติมยอดให้อัตโนมัติตามยอดคงค้าง แก้ไขได้)
7. กด **บันทึกเช็ค**

ยอดตัดชำระรวมต้องไม่เกินยอดเช็ค — ระบบตรวจให้ก่อนบันทึก

### 7.2 ติดตามสถานะเช็ค

ที่หน้ารายละเอียดเช็ค เลือกสถานะแล้วกด **อัปเดตสถานะ**

| สถานะ | ความหมาย |
| --- | --- |
| รับเช็คแล้ว | ผู้แทนรับเช็คจากโรงพยาบาล |
| นำฝากแล้ว | นำเข้าบัญชีธนาคารแล้ว |
| เงินเข้าแล้ว | เช็คเคลียร์สำเร็จ (นับเป็นเงินที่จัดเก็บได้) |
| เช็คเด้ง / คืนเช็ค | ไม่สามารถเรียกเก็บได้ — ระบบจะ**ไม่นับ**ยอดนี้เป็นเงินที่จัดเก็บ และใบแจ้งหนี้กลับมาเป็นหนี้ค้าง |

### 7.3 ไฟล์ scan เช็ค

กด **+ อัปโหลด** ในหน้ารายละเอียดเช็ค แนบรูปหรือ PDF (≤ 10 MB)

## 8. โรงพยาบาล

ตารางแสดงรหัส ชื่อ ประเภท จังหวัด ภาค ผู้แทนผู้รับผิดชอบ ผู้ประสานงาน และจำนวนสัญญาที่ใช้งานอยู่

กด **+ เพิ่มโรงพยาบาล** หรือ **แก้ไข** เพื่อกำหนด:
- ภาค (`region_id`) — ใช้กำหนดขอบเขตข้อมูลของผู้แทน
- ผู้แทนผู้รับผิดชอบ (`rep_id`) — ใช้ในรายงานตามผู้แทน

---

## 9. รายงาน

เลือก **ณ วันที่**, **ภาค**, **ผู้แทน** แล้วเลือกแท็บ

| แท็บ | ใช้ทำอะไร |
| --- | --- |
| ตามผู้แทน | เทียบผลงานแต่ละผู้แทน: งวดทั้งหมด, แจ้งแล้ว, ค้างแจ้ง, มูลค่าคงเหลือ, แจ้งหนี้รวม, รับเช็ค, ค้างรับ, อัตราการเก็บ |
| ตามโรงพยาบาล | เช่นเดียวกันแต่แยกตามโรงพยาบาล |
| อายุหนี้ | ยอดค้างชำระแบ่งช่วง ≤30 / 31–60 / 61–90 / >90 วัน พร้อมรายการใบที่ค้างเรียงตามอายุหนี้ |
| การส่งใบแจ้งหนี้ | สัญญาที่มีใบแจ้งหนี้แต่ยังไม่มีหลักฐานการส่ง (จำนวนใบ/ส่งแล้ว/ยังไม่ส่ง) |
| ยังไม่แจ้งหนี้ | รายการงวดที่ถึงรอบแล้วแต่ยังไม่ส่งใบแจ้งหนี้ พร้อมมูลค่าโดยประมาณและจำนวนวันเกินกำหนด |
| ยังไม่ได้รับเช็ค | ใบแจ้งหนี้ที่ออกแล้วแต่ยังไม่ได้รับเช็ค พร้อมการส่งล่าสุด |

แท็บ "ตามผู้แทน" และ "ตามโรงพยาบาล" มีปุ่ม **ดาวน์โหลด CSV** (เปิดใน Excel ได้ทันที รองรับภาษาไทย)

### วิธีอ่านค่า "ค้างแจ้ง (งวด)"

นับเฉพาะงวดที่ `วันเริ่มงวด ≤ ณ วันที่` และยังไม่มีใบแจ้งหนี้ ตัวอย่าง:

> สัญญา 30,000 บาท/เดือน ต.ค. 2569 – ก.ย. 2570 ณ 20 พ.ย. 2569 → เริ่มแล้ว 2 งวด (ต.ค., พ.ย.)
> ถ้าออกใบแจ้งหนี้แล้ว 1 งวด → ค้างแจ้ง 1 งวด, มูลค่าคงเหลือ = 11 × 30,000 = 330,000 บาท

กรณี **จ่ายตามใช้** ระบบใช้ค่าเฉลี่ยของยอดที่เรียกเก็บได้แล้วในสัญญานั้นเป็นมูลค่าประมาณของงวดที่เหลือ

## 10. ผู้ใช้งาน (ADMIN)

- เพิ่มผู้ใช้: ชื่อ อีเมล บทบาท ภาค โทรศัพท์ รหัสผ่าน (≥ 8 ตัวอักษร)
- แก้ไข: เปลี่ยนบทบาท/ภาค/สถานะ หรือตั้งรหัสผ่านใหม่ (เว้นว่าง = ไม่เปลี่ยน)
- ปิดใช้งานบัญชีด้วยการเอาติ๊ก "เปิดใช้งานบัญชี" ออก — ประวัติยังอยู่ครบ

---

## 11. บันทึกการใช้งาน (ADMIN)

แสดงทุกเหตุการณ์: ใคร ทำอะไร กับข้อมูลใด เมื่อไร จาก IP ไหน กรองตามการกระทำและประเภทข้อมูลได้ ใช้ตรวจสอบเมื่อมีข้อโต้แย้งกับลูกค้า

---

## 12. คำถามที่พบบ่อย

**ออกใบแจ้งหนี้ผิดงวด ทำอย่างไร**
ไปที่ใบแจ้งหนี้ → ยกเลิกใบแจ้งหนี้ แล้วออกใหม่จากหน้างวดในสัญญา

**สัญญาเป็นใบสั่งจ้างรายเดือนระหว่างรอสัญญาปี**
สร้างเป็นประเภท `ใบสั่งจ้าง` โดยตั้งวันเริ่ม–สิ้นสุดตามเดือนนั้น แล้วผูกกับโรงพยาบาลเดิม เมื่อเซ็นสัญญาจริงจึงสร้างสัญญาใหม่ (หรือใช้ปุ่ม "ต่อสัญญาใหม่")

**งวดขึ้นไม่ตรงกับที่ต้องการ**
ระบบแบ่งงวดจากวันเริ่ม–สิ้นสุดที่กรอก: รายเดือนจะตัดที่สิ้นเดือน, รอบ 10/15 วันจะนับตามจำนวนวัน ถ้าต้องการเริ่มกลางเดือน ให้ปรับวันเริ่มให้ตรงรอบที่โรงพยาบาลจ่าย

**ลืมบันทึกการส่งย้อนหลังได้ไหม**
ได้ — เลือกวันที่ในอดีตในฟอร์มบันทึกการจัดส่ง ระบบเก็บลำดับตามวันที่ที่บันทึก

**ลบสัญญาได้ไหม**
ไม่มีการลบถาวร ใช้การยกเลิก/ปิดสถานะเพื่อรักษาประวัติทางบัญชี
